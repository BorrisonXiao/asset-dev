What errors do the four Mandarin ASR systems make?

ASSET has the lowest character error rate (CER). Its largest error reduction is in substitutions. The analysis covers 7,128 test utterances in each of 12 runs across three seeds.

What explains the CER gap

Substitutions account for the largest gain. ASSET averages 7.10 substitutions per 100 reference characters, versus 8.10 for the character oracle, 8.55 for the fixed grid and 12.27 for the phone oracle. Table 2 also shows lower insertion and deletion rates for the character oracle than for ASSET.

Residual errors still matter. ASSET transcribes 54.4% of utterances exactly on average. Frequent substitutions include 他 ↔ 她 and 城 → 成. These pairs share a Mandarin pronunciation in the relevant readings. The phone oracle also has the highest deletion and insertion rates, with examples of dropped phrases and repetition.

The comparison covers complete systems. The oracles use transcript-assisted boundaries, the baselines train for ten CE epochs, and ASSET uses 24,000 updates including a 2,400-update warmup with the seed-matched phone decoder. The results combine differences in boundary placement, token budget and training. Transcript examples establish edit patterns and help identify cases for acoustic review.

Data and scoring

The replication used seeds 3407, 3408, 3409 and a shared filtered test manifest. Each prediction file covers all 7,128 manifest IDs with matching reference tokens. Independent scoring reproduces the saved CER numerator and denominator for every run.

The archived scorer inserts underscores between words before computing character edits. The character-only analysis removes these separators and computes minimum-edit alignments with diagonal, deletion, then insertion tie priority. Equally optimal alignments can redistribute edits across types.

The new ASSET runs apply the rate penalty as an auxiliary loss. Historical Table 3 used a reward-side rate penalty. The test manifest excludes 48 utterances from the full AISHELL-1 test split. All runs use development CER for checkpoint selection.

Background sources include the ASSET paper, Table 3 and the original multilingual results report.
